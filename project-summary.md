# Project Summary

## Title

Sales Forecast Analysis Using Tableau

## Course Context

This was completed as a Data Visualization mini project for MSc IT in Data Science.

## Business Problem

Businesses need to understand sales performance, product demand, customer segment behavior, discount impact, and marketing effectiveness. A Tableau dashboard helps users explore these insights visually and supports better planning.

## Analysis Areas

- Sales trend analysis
- Marketing spend vs sales
- Sales by product category
- Discount analysis
- Customer segment analysis
- Total sales
- Estimated profit
- Profit ratio
- Sales forecasting

## Deliverables

- Tableau worksheets
- Tableau dashboard
- Tableau story
- Mini project report
- Sample dataset previews

## Repository Note

This repository is designed for portfolio presentation. It includes sample data previews and visual outputs so recruiters can understand the project without needing the full local dataset environment.
